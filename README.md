# OLDfag.exe 2.0 — готовый сайт для GitHub Pages

Это **новая версия сайта**, не патч старого. В корне архива находится `index.html`.

## Состав

- `index.html` — Артур и проверка на вход, клуб «Компы», три тематических квиза, игровая аркада
- `app.js`, `questions.js`, `arthur-dialogues.js`, `styles.css` — входной квиз и реплики Артура
- `club.js`, `club.css`, `club-questions.js` — интерактивная комната и 900 вопросов (3×300)
- `audio.js` — единая фоновая музыка и звуковые эффекты клуба
- `assets/` — изображения Артура/клуба, портреты NPC, музыка и звуки
- `arcade/index.html` + `arcade/game.js` + `arcade/assets/` — полная игра «Тимур vs Морженальность» из последней рабочей сборки 0.16.2
- `club-questions-editable.json` — редактируемый банк тематических вопросов

## Запуск

Откройте `index.html` в браузере на ПК. Для телефона надёжнее открывать через опубликованный GitHub Pages сайт, а не приложение «Файлы» iOS.

Для локального запуска со всеми функциями браузера, на ПК можно также запустить в папке сайта команду `python -m http.server 8000`, затем открыть `http://localhost:8000/`.

## Установка на GitHub Pages, отдельная новая страница

1. Создайте в GitHub **новый публичный репозиторий** `oldfag-exe-2`, не трогая старый `oldfag-exe`.
2. Откройте новый репозиторий, используйте **Add file → Upload files**.
3. Распакуйте этот ZIP и загрузите в корень нового репозитория **все файлы и папки** из распакованной папки. Важно: именно `index.html` должен оказаться в корне, а не на уровень ниже.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**, установите **Deploy from a branch**, Branch **main**, Folder **/(root)** и **Save**.
6. После публикации сайт будет иметь адрес вида `https://<username>.github.io/oldfag-exe-2/`.

**Внимание о вложенных папках.** Веб-интерфейс GitHub иногда неудобно загружает большие деревья папок. Если вы загрузили ZIP напрямую, Pages его не распакует. Проще использовать GitHub Desktop или загрузить файлы в соответствующие каталоги `assets/` и `arcade/assets/` (соблюдая регистр имён файлов). Или импортировать распакованную папку через git.

Старый опубликованный сайт при этой процедуре останется нетронутым.
