# Крымский чай — публикация в игровом автомате

Ветка готовит второй слот автомата к игре «Крымский чай», но **не должна сливаться в main, пока не загружена папка игры с ресурсами**.

## Что уже сделано в ветке
- Во втором слоте GAME SELECT появилась рабочая кнопка «Крымский чай».
- Карточка использует `krymskiy-chai/arcade_icon.webp`.
- При запуске загружается `krymskiy-chai/index.html` в тот же iframe, что использует игра «Тимур».
- При возвращении в клуб iframe выгружается. Другие слоты не изменены.

## Что остаётся перед публикацией
1. Распаковать предоставленный архив `Krymskiy_Chai_v1_2_PUBLIC_RELEASE.zip` (он содержит **папку** `krymskiy-chai`).
2. Добавить эту папку **в корень репозитория этой ветки**, вместе со всеми PNG/WebP, JS, CSS и `finale/`. ZIP нельзя загружать в GitHub как один файл: GitHub Pages сам ZIP не распакует.
3. Проверить загрузку `krymskiy-chai/index.html`, графику, переход 100/300/400 очков и мобильную компоновку.
4. После проверок слить ветку в `main`, чтобы игра появилась на публичном сайте.

Саму игровую сборку v1.2 подготовили без кнопок тестового режима, выбора скорости и тренировочного запуска уровня 2. На 100 очках короткая надпись появляется без паузы; курс сложности v1.1 сохранён.
